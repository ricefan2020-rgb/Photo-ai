# 平面配置

把售樓平面圖收成以公厘計的 CAD。第一段只做這件事：上傳圖或 PDF（斜放的頁會自動拉正）、必要時再手動轉正、用兩個已知點校正比例、再用另一段長度覆核、沿牆中心線描成雙線、標房間名，然後匯出 ASCII DXF 和一頁 PDF 預覽。

沒有伺服器，沒有模型，沒有櫃體圖塊，也不讀寫 DWG。底圖只留在瀏覽器裡，不嵌進 DXF。

圖上固定帶一句：**此圖依平面圖繪製，下單前須現場丈量。**

## 容許誤差

覆核的實測長度可以比圖上短 5 mm，不可以長過圖上的數字。短超過 5 mm，或比圖上長，DXF 和 PDF 都不能匯出。

## 開啟

```bash
npm install
npm run dev
```

瀏覽器打開終端機顯示的本機網址。用桌面寬度。

1. 上傳 JPG、PNG，或 PDF 的一頁。斜放的售樓圖會依牆線和尺寸線自動拉正，頁面上會寫已自動拉正。
2. 若自動拉正不準，再用旋轉或兩點把牆拉平。
3. 在一段已知尺寸的兩端點一下，輸入印刷的公厘。
4. 再用另一段獨立的已知長度覆核。
5. 沿牆點中心線。牆厚預設 150 mm。閉合的牆會標內側淨距。
6. 點在房間裡，輸入名稱，例如主臥、客廳。
7. 覆核通過後下載 `plan.dxf` 與 `plan-preview.pdf`。

滾輪縮放，中鍵或右鍵拖曳平移，描牆時會吸到已有的牆。案子存在這個瀏覽器裡，重新整理不會消失，也可以下載 JSON。

```bash
npm test
```

測試確認：已知傾斜的牆會被拉平；覆核短 5 mm 可以匯出，長過圖上尺寸會被擋住。

DXF 為 AutoCAD 2000（AC1015）ASCII，單位公厘（`$INSUNITS = 4`）。圖層是 `WALL`、`ROOM`、`DIM`、`NOTE`。中文在 DXF 裡寫成 CAD 的 `\U+` 碼，PDF 預覽則直接畫出字形。
